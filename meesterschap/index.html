Meesterschap

Meesterschap gesprek 1

Ik ben Romy, een 3e jaars student informatica aan de hogeschool Inholland in Haarlem. Op dit moment volg ik de minor Web design & development bij de HvA. Hier hoop ik meer te leren over design en front-end development. Ik ben 21 jaar oud en kom uit de buurt van Schagen. In mijn vrije tijd game ik graag, daarnaast speel ik ook graag bordspelletjes. Ik heb een hond genaamd Liz, een Friese stabij.

Mijn leerdoelen

Voor het begin van de minor heb ik een paar leerdoelen gesteld:

  • Ik wil beter worden in animaties met CSS, zodat ik betere code schrijf, waardoor mijn websites visueel aantrekkelijker zijn zonder dat dit veel tijd kost.
  • Ik want meer leren over het toegankelijk maken van een website, zodat mijn websites toegankelijker zijn en beter worden opgepikt door zoekmachines.
  • Ik wil beter worden in samenwerken en daarin met name het leiden van een groep. Dit wil ik later ook kunnen toepassen tijdens mijn werk als dit nodig is.

Meesterschap gesprek 2

Tijdens de laatste paar weken heb ik gemerkt dat ik echt ontzettend gegroeid ben, met name in CSS heb ik echt veel voortgang gemaakt. Soms vind ik het nog lastig om mij aan een thema te houden tijdens het maken van een project, hier probeer ik ook meer op te letten. Tijdens het vak API vind ik dat ik hier wel een goede stap in heb gemaakt, omdat ik hier echt een duidelijk thema had en ik hier ook echt aan heb gehouden. Ik merk ook dat ik snel AI wil gebruiken om bijvoorbeeld documentatie voor mij te lezen. Ik wil dit wel minder gaan doen, omdat ik merk dat ik minder leer en dat ik sommige dingen dan nog mis.

Mijn leerdoelen voor de meesterproef

Voor het begin van de minor heb ik een paar leerdoelen gesteld:

  1. Ik wil beter worden in het overdragen van mijn kennis en hierbij beter worden in het pitchen van mijn ideeën.
  2. Ik wil beter worden in het ontwerpen van een website, hierbij doel ik op het aanhouden van een thema en zorgen voor een goede flow van de website.
  3. Ik wil beter worden in samenwerken en daarin met name het leiden van een groep. Dit wil ik later ook kunnen toepassen tijdens mijn werk als dit nodig is.

Om het eerste leerdoel te bereiken ga ik dieper in op documentatie, ook wil ik mijn kennis niet uit AI halen. Zodat ik 100% zeker weet dat het juiste informatie is.

Om het tweede leerdoel te bereiken wil ik meer inspiratie gaan opdoen uit andere websites. Verder ga ik meer mensen feedback vragen over mijn ontwerpen.

Om het derde leerdoel te bereiken wil ik tijdens mijn meesterproef de leiding nemen door de voortgang goed in de gaten te houden. Ook wil ik mijn groep hulp aanbieden als ze dit nodig hebben.

Meesterschap gesprek 3

Tijdens de meesterproef heb ik mij vooral gericht op het ontwerpen en het leiden van een groep. Het ontwerpen vind ik nogsteeds lastig, ookal heb ik geprobeerd om een nieuw logo voor Videlio te ontwerpen. Ik denk ook niet dat het ontwerpen iets is wat ik echt leuk vind. Ik zou het in de toekomst liever niet willen doen. Ik vind het wel leuk om een ontwerp tot leven te brengen met html, css en JavaScript.

Tijdens de meesterproef vond ik dat het leiden ook wel goed ging. Vooral in het begin, toen hielden we het trello bord bij. Verder vond ik het ook leuk om contact te hebben met de opdrachtgever, ookal was dit op sommige momenten nogal frustrerend. Ik ben trots op mijn professionaliteit richting de opdrachtgever toe. Ook ben ik blij dat ik meer heb geleerd over hoe je wordpress als headless CMS kan gebruiken.

Ik vind het fijn dat ik aan al mijn leerdoelen heb kunnen werken. Ik ben blij dat ik mijn kennis heb kunnen overdragen en ik merkte ook dat ik hier steeds zelfverzekerder mee werd.

Ik vond de talk van Leonie Watson erg interessant, het was fijn om te zien dat AI ook slechtzienden kon helpen met digitale toegankelijkheid.

Verder vond ik een hoogtepunt van de vakken toch wel het vak API. Hier heb ik veel van geleerd, ik vond het ook super leuk om te werken met een externe API als spotify. Het was uitdagend voor mij en ik vond het leuk omdat ik lekker kon JavaScripten.

Hoe verder?

Volgende periode zal ik een cloud minor gaan doen bij mijn eigen school in Haarlem. Hier zal ik van alles gaan leren over cloud en backend development. Ik kijk daar vooral naar uit omdat het weer iets anders is dan wat we in deze minor hebben gedaan.
