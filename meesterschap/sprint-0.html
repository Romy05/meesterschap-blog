Sprint 0

Tijdens sprint 0 heb ik een memory spel gemaakt en een paar kaarten op elkaar die uit kunnen klappen. Ik heb tijdens deze 2 weken vooral veel geëxperimenteerd met wat ik allemaal nog kon in CSS, het wat vooral een soort opfris project. Ook heb ik super veel kunnen leren over CSS animaties en hoe ik dit ook in 3D kan doen. Dat vond ik zelf echt ontzettend vet. Toch merkte ik dat mijn project niet zo mooi was als die van sommige klasgenoten, daarom kreeg ik alleen maar meer motivatie om mee te doen aan deze minor. Ik wilde namelijk groeien in mijn design vaardigheden. Ik vond het super leuk om met JavaScript de memory game te maken, maar toen ik zag wat klasgenoten konden met alleen CSS raakte ik echt geïnspireerd. Ik wilde ook leren hoe ik met alleen CSS een functionele website kon maken. Ik vond sprint 0 een goede start van de minor, omdat ik mijn eigen ideeën en vaardigheden kon laten zien zonder dat er harde randvoorwaarden aan vast zaten.
