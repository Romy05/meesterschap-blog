Browser Technologies

Tijdens BT kregen wij de opdracht om een deel van het Nederlandse erfbelastingsformulier om te zetten naar het web. Om verdachting van poging tot fraude/oplichting tegen te gaan hebben we de huisstijl van de NS gepakt en deze toegepast op ons ontwerp. In het verleden is het wel eens voorgekomen dat een student is aangesproken door een externe partij over het feit dat het formulier ontzettend lijkt op die van de belastingdienst. Dat wilden we nu graag voorkomen!

Ik vond het op sommige momenten erg lastig, omdat iets dat werkt op papier, zal niet altijd even goed werken op het web. Daarom heb ik goed na moeten denken over hoe ik het formulier wilde implementeren.

Voor de opdracht moest ik minimaal 2 design patterns implementeren in het formulier. Voor het eerste design pattern heb ik openklappende vragen gemaakt. Dit pattern zorgt ervoor dat vragen die de gebruiker niet hoeft te beantwoorden worden geskipt zonder dat de gebruiker er erg in heeft.

Het tweede design pattern wat ik heb gebruikt is het kiezen tussen het aangeven van een bepaald nummer. Hier heb ik meerdere opties voor geprobeerd. Uiteindelijk kwam ik uit bij een optie waarbij je eerst moest selecteren welk nummer je wilde gebruiken, waarna er meer informatie werd getoond.

Ik vond dit vak ontzettend interessant, hierbij met name het toegankelijkheid maken van een website en welke extra features html elementen hebben. Ik merkte tijdens het maken dat ik het lastig vond om de NS style aan te houden. Dit kan ik de volgende keer beter doen door rustig te beginnen met het maken van componenten en meer onderzoek te doen naar de style. Ik vond het ook erg lastig om ervoor te zorgen dat mijn website toegankelijk was zonder javascript. Verder heb ik geleerd hoe ik moet valideren met JavaScript en hoe ik de validatie berichten ook toegankelijk maak.

Wat ik de volgende keer anders zou doen is: - Meer diepgaand onderzoeken van patterns, zodat ik gelijk een goede manier kies. - Meer onderzoek doen naar de componenten van het gegeven design system, hierdoor zijn de componenten gelijk goed. - Meer informatie toevoegen aan het begin van een formulier, zodat de context voor de gebruiker ook duidelijk is.
