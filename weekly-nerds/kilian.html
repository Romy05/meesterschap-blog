Weekly Nerd: Kilian

Kilian was de eerste Weekly Nerd spreker en kwam op 4 februari ons niet alleen vertellen over html elementen en -attributen, maar ook over CSS trucjes om elementen te stylen.

Ik vond het interessant om te zien dat je input elementen helemaal zelf kon stylen hoe je wilden met bepaalde trucjes. Ik dacht hiervoor dat het juist erg lastig zou zijn om de standaard browser lay-out weg te krijgen, maar dit bleek achteraf super erg mee te vallen!

Ook heb ik geleerd dat je er bijvoorbeeld voor kan zorgen dat alle browser styling weggaat van een input element met "appearance: none;". Dit is super handig om te gebruiken zodra je een input gaat stylen.

Ook liet hij een paar andere trucjes zien:

  • Met scroll-behavior: smooth; op het html-element kun je de pagina vloeiend laten scrollen naar links.
  • Met scroll-margin-top kun je voorkomen dat een element achter een sticky of fixed header verdwijnt wanneer je naar een ankerlink scrollt.
  • De :target pseudo-class kun je gebruiken om een element te stylen nadat ernaartoe is genavigeerd. Hiermee kun je bijvoorbeeld een highlight- of fade-in-animatie uitvoeren op het doel-element.
  • Met @starting-style in CSS kun je animaties toevoegen aan een "<dialog>" wanneer deze geopend wordt.

Dit zijn dingen die ik wel echt kan gebruiken in mijn websites, dus ik vond dit echt een interessante spreker!
