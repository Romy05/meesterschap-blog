Weekly Nerd: Peter Paul Koch

Peter Paul Koch is de maker van quirksmode.org, de voorganger van MDN. Hij heeft al jaren ervaring met web development en weet veel over browser geschiedenis. Daarom kwam hij 19 februari langs om ons hierover te vertellen.

Eerst legde hij ons uit waar een browser allemaal uit bestaat. Een browser heeft een rendering engine, een javascript engine en een interface. De rendering engine is in feite alles van een browser behalve de javascript engine en de interface. Het is verantwoordelijk voor HTML en CSS parsing en rendering, constructie van de DOM en AOM trees.

De DOM is de manier waarop javascript met delen van HTML kan interacteren. De AOM is de toegankelijkheidsversie hiervan.

PPK vertelde ook over de term ‘Backward compatibility’. Dit betekent dat als er ooit iets heeft gewerkt in de browser, zal dit voor altijd moeten blijven werken. Dit betekent dat een website uit 2000 nu nog steeds zou moeten werken als dat het deed in het jaar 2000.

Hier zijn wel enkele uitzonderingen van. Bijvoorbeeld het blink element, dat is een html element wat ervoor zorgde dat de tekst in het element verdween en weer verscheen, keer op keer. Je kunt dit natuurlijk wel namaken met CSS.
