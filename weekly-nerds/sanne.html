Weekly Nerd: Sanne

Op 11 maart kwam Sanne ons vertellen over zijn ervaringen met CSS. Hij liet hierbij een aantal experimenten, die hij heeft gemaakt met CSS, zien en lichtte het toe. Hij vertelde hoe hij op deze ideeën is gekomen en nam ons mee in zijn gedachtegang tijdens het experimenteren met CSS.

Ik stond echt versteld van twee experimenten die Sanne liet zien. Dit waren de Newton’s cradle en een experiment waarbij hij perspectief liet zien van meerdere kanten. Ik vond het zo bijzonder dat een 3D animatie in CSS er zo echt uit kan zien. En dat je natuurkunde in je CSS stopt vind ik echt ontzettend creatief.

Voordat ik begon aan de minor had ik mijn aandeel aan kennis over html en CSS, maar er was nog zo veel waarvan ik niet eens wist dat het bestond. Toen ik er achter kwam dat het mogelijk is om 3D objecten te maken in CSS was ik echt verbaasd. Ik wilde daar toen ook direct mee aan de slag, daarom heb ik tijdens Sprint 0 geëxperimenteerd met 3D animaties. Ook heb ik voor het vak CSS to the rescue een 3D omgeving gemaakt omdat ik het super interessant vond.

Ik vond het super gaaf om te zien wat je allemaal met CSS kunt doen eigenlijk en ik wil zeker blijven experimenteren. Om mijn blog persoonlijkheid te geven wil ik proberen om met alleen CSS een ‘Kuromi’ poppetje te maken. Het lijkt me echt geweldig als me dat zou lukken.
